# Desktop CI/CD Spec (`isaiah` branch)

This spec defines desktop artifact build and distribution for `desktop/`.

## Goals

1. Build macOS desktop binaries from `desktop/` only.
2. Produce demo-ready download artifact (`.dmg`).
3. Publish artifacts to:
- GitHub Releases (immediate fallback)
- Cloudflare R2 (preferred download origin)
4. Keep backend/web deploy pipeline independent.

## Artifacts

Generated by ElectroBun build in `desktop/artifacts/`:
- `*-clawed-chat-desktop-*.dmg`
- `*.app.tar.zst`
- `*-update.json`
- `desktop-release-manifest.json` (generated by `prepare-release.sh`)

## CI Workflow (template)

Workflow template is in:
- `desktop/ci/workflows/desktop-release.yml`

Install it by copying to root:
- `.github/workflows/desktop-release.yml`

Trigger modes:
- Manual (`workflow_dispatch`) with channel input (`stable`/`canary`)
- Tag push (`desktop-v*`)

## Required GitHub Settings

Repo variables:
- `DESKTOP_CLOUDFLARE_ACCOUNT_ID`
- `DESKTOP_CLOUDFLARE_R2_BUCKET`
- `DESKTOP_CLOUDFLARE_R2_PUBLIC_BASE_URL`

Repo secrets:
- `DESKTOP_CLOUDFLARE_R2_ACCESS_KEY_ID`
- `DESKTOP_CLOUDFLARE_R2_SECRET_ACCESS_KEY`

Optional existing secret:
- `DESKTOP_CLOUDFLARE_API_TOKEN`

## Current env findings

- `gh` CLI is authenticated and usable.
- Cloudflare account ID is derivable from current zone token.
- Current Cloudflare API token returns `403` for `r2/buckets` API.

Implication:
- You can run GitHub-release-only CI right now.
- For R2 publishing, create an R2-scoped token or R2 API key pair.

## Setup commands (local)

Bootstrap variables from current `app/.env`:

```bash
cd desktop
./ci/scripts/bootstrap-gh-vars.sh isaiahb/clawed.chat
```

Set R2 key secrets once generated in Cloudflare dashboard:

```bash
gh secret set DESKTOP_CLOUDFLARE_R2_ACCESS_KEY_ID --repo isaiahb/clawed.chat
gh secret set DESKTOP_CLOUDFLARE_R2_SECRET_ACCESS_KEY --repo isaiahb/clawed.chat
```

## Release commands (local)

Canary:

```bash
cd desktop
bun run build:canary
./ci/scripts/prepare-release.sh canary
```

Stable:

```bash
cd desktop
bun run build:release
./ci/scripts/prepare-release.sh stable
```

Publish built artifacts to R2 from local machine:

```bash
cd desktop
export CLOUDFLARE_ACCOUNT_ID="..."
export CLOUDFLARE_R2_BUCKET="clawed-desktop-downloads"
export CLOUDFLARE_R2_ACCESS_KEY_ID="..."
export CLOUDFLARE_R2_SECRET_ACCESS_KEY="..."
export CLOUDFLARE_R2_PUBLIC_BASE_URL="https://downloads.clawed.chat"
./ci/scripts/publish-r2.sh
```

## Conflict-safe rollout order

1. Add workflow file in root `.github/workflows/` from template.
2. Set repo vars/secrets.
3. Run workflow manually with `publish_to_r2=false` first.
4. Verify DMG appears on GitHub Release.
5. Enable `publish_to_r2=true` after R2 keys are confirmed.
